# Reusable Template Product Plan

Goal: later sell as a `₹199-₹499` digital template.

## Remove Client-Specific Data

- Real student names
- Real phone numbers
- Real parent names
- Real batch names if identifiable
- Real payment entries
- Real support messages
- Real business branding unless selling as done-for-you setup

## Keep Sample Data

Keep 20 fictional students with Indian-style names, demo phone numbers, mixed batches, and mixed payment statuses.

Keep sample months, dashboard examples, pending messages, and reports so buyers understand the workflow.

## Protect Formulas And Structure

- Protect header rows in every tab.
- Protect Dashboard summary cells.
- Protect Pending message formula/output columns if using formulas.
- Leave editable columns in Config, Students, Payments, and Message Templates.
- Add note: "Do not rename tabs or edit header rows."

## Setup Instructions

Use a `README` tab with:

1. Make a copy of the Google Sheet.
2. Edit Config.
3. Replace demo students with your students.
4. Enter payments in Payments tab or use menu.
5. Refresh Dashboard.
6. Generate Pending List.
7. Copy WhatsApp messages manually.

## Gumroad / Marketplace Description

Title: DuesFlow Google Sheets Template

Short description:
Track student fees, pending payments, monthly collection, and WhatsApp reminder messages in one simple Google Sheet.

Long description:
This template is made for tuition centers and small coaching centers who currently track fees in notebooks, WhatsApp, or basic Excel files. It helps you see who paid, who is pending, how much was collected, and which students need reminders.

Includes:

- Student list
- Payment tracker
- Paid, partial, pending, and overpaid status
- Dashboard
- Pending fee list
- Ready-to-copy WhatsApp reminder messages
- Monthly report
- Setup instructions

No app install. No login. No paid tools. Works inside Google Sheets.
